# Updates from GitHub Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** AutoShelf finds a newer release on GitHub, tells the user once per version, and installs it only when the user clicks Update, reopening on the new version.

**Architecture:** `autoshelf/updates.py` (no Qt) reads the latest release from the GitHub API, picks the installer and its `.sha256`, downloads and verifies, and starts the installer silently. `AppService` adds the settings and the once-per-version bookkeeping. The app checks at start and then hourly (a check is due after 24 h), shows a notification with an Update button, and Settings gets an Updates group with an Update dialog (notes, progress, Cancel). The installer reopens AutoShelf when started with `/AUTOSHELFUPDATE`; the release workflow publishes the checksum.

**Tech Stack:** Python 3.13 stdlib `urllib`/`hashlib`/`subprocess`, PySide6 + qfluentwidgets, Inno Setup, GitHub Actions, pytest/pytest-qt.

**Spec:** `docs/superpowers/specs/2026-10-30-updater-design.md`

## Global Constraints

- Repository `HarukiU06/Folder-sorting-system`; API `https://api.github.com/repos/HarukiU06/Folder-sorting-system/releases/latest`.
- Assets `AutoShelf-X.Y.Z-setup.exe` and `AutoShelf-X.Y.Z-setup.exe.sha256` (hex digest, two spaces, file name); both URLs must start with `https://github.com/HarukiU06/Folder-sorting-system/releases/download/`; the final (redirected) URL must be `https`.
- Installer arguments: `/VERYSILENT /SUPPRESSMSGBOXES /NORESTART /AUTOSHELFUPDATE`.
- Downloads go to `%APPDATA%\AutoShelf\cache\updates\` (`paths.cache_dir / "updates"`), never the iCloud root.
- Nothing installs or downloads before the user clicks Update. No pre-releases or drafts. Offline or any error: silent, logged.
- Settings: `check_updates` (default on), `update_checked` (ISO time), `update_notified` (version).
- From source: no Update button ("Running from source: update with git pull"). Portable copy (no `unins000.exe` next to `AutoShelf.exe`): Update opens the release page.
- Tests never use the network (the `no_network` fixture also blocks `updates._urlopen`).
- Version 0.2.0 in `pyproject.toml`, `autoshelf/__init__.py` and the `.iss` default. Never push tags.

## Review Focus

1. Offline, rate-limited (HTTP 403) or malformed API answer: no crash, no notification; Settings says it couldn't check (Task 1 `test_latest_release_wraps_errors`, Task 4 UI test).
2. A latest release without the `.sha256` asset (0.1.0 and any hand-made release): no Update is offered (Task 1 `test_release_without_checksum_offers_nothing`).
3. A download cut off or corrupted: AutoShelf's partial file is removed, nothing runs, Update can be tried again; other files in the folder stay (Task 1 `test_download_mismatch_removes_only_its_own_file`).
4. The portable copy: Update opens the release page and never starts an installer (Task 4 `test_portable_copy_opens_the_release_page`).
5. Clicking the notification's Update after AutoShelf was restarted (no release in memory yet): it checks first, then opens the dialog (Task 4 `test_update_link_checks_first`).

### Task 1: `autoshelf/updates.py`

**Files:** Create `autoshelf/updates.py`, `tests/test_updates.py`; modify `tests/conftest.py` (`no_network` also patches `updates._urlopen`).

**Interfaces — Produces:**
- Constants `REPOSITORY`, `LATEST_URL`, `DOWNLOAD_PREFIX`, `RELEASES_PAGE`, `CHECK_HOURS = 24`, `UPDATE_FLAG = "/AUTOSHELFUPDATE"`, `INSTALL_ARGS`, modes `INSTALLER`, `PORTABLE`, `SOURCE`.
- `class UpdateError(Exception)`.
- `@dataclass(frozen=True) class Release: version: str; notes: str; page: str; installer_url: str; installer_name: str; size: int; checksum_url: str`.
- `parse_version(text: str) -> tuple[int, int, int] | None` ("v0.3.0" and "0.3.0"; anything else None).
- `is_newer(version: str, installed: str = autoshelf.__version__) -> bool`.
- `release_from(data: dict) -> Release | None` (None for a draft/pre-release, a bad tag, a missing installer or checksum asset, or a URL outside `DOWNLOAD_PREFIX`).
- `latest_release(fetch: Callable[[str], bytes] | None = None) -> Release | None` (the newest published release, newer or not; `fetch` defaults to `http_get`; any `OSError`/`ValueError` becomes `UpdateError`).
- `http_get(url: str) -> bytes` (via `_urlopen`, `User-Agent: AutoShelf/<version>`, `Accept: application/vnd.github+json`, timeout 15 s, max 1 MB).
- `download(release: Release, folder: Path, *, progress: Callable[[int, int], None] | None = None, cancelled: Callable[[], bool] = lambda: False) -> Path` (reads the checksum, streams the installer to `<name>.part` via `_urlopen` hashing as it goes, checks the final URL is https, verifies, `os.replace` to `<name>`; on mismatch, error or cancel removes only the `.part` and raises `UpdateError`).
- `install_mode(executable: Path | None = None, frozen: bool | None = None) -> str`.
- `start_installer(path: Path, *, popen=subprocess.Popen) -> None` (detached: `DETACHED_PROCESS | CREATE_NEW_PROCESS_GROUP` on Windows, `close_fds=True`).
